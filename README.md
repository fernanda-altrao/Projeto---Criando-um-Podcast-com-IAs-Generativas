# Projeto---Criando-um-Podcast-com-IAs-Generativas
O que é a IA 🌌
📒 Descrição
Este podcast apresenta de forma simples e objetiva o que é a IA.
🤖 Tecnologias Utilizadas
•	IA Generativa ChatGPT para roteirização;
•	IA Generativa ElevenLabs para criar o podcast;
•	Ferramenta Word para edição.
🧐 Processo de Criação
Utilizei o "ChatGPT" para revisar minha pesquisa sobre o que é IA, estruturar o conteúdo e refinar minhas ideias. Por outro lado, o "ElevenLabs" foi usado para gerar o podcast. Para concluir, a montagem final foi feita no Word, por ser uma ferramenta simples para edição de texto.
🚀 Resultados
O podcast apresenta um conteúdo envolvente, demonstrando de forma simples e objetiva o que é a IA.
💭 Reflexão
Criar este podcast foi uma experiência sobre o potencial criativo das IAs e como elas podem ser aplicadas no cotidiano de forma simples e para várias finalidades.
